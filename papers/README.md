# Papers

| File | Content |
|---|---|
| `LLM_Analysis_Merged.pdf` | the project monograph — *RMT & LLM: spectral analysis of activations, the mathematical inevitability of hallucinations, and the RLHF utility trap* |

The monograph is the theoretical backbone of this repository:

- the Marchenko-Pastur / BBP / Tracy-Widom machinery implemented in
  `src/rmt_llm/`;
- the "10 paths to N_crit" argument (Keating-Snaith, Caputo, Landauer, ...);
- the Utility Trap and Hallucination Cliff phenomena that the empirical
  pipelines in `research/tinygpt_formula/` test directly.

Cite via the repository `CITATION.cff` (Zenodo DOI
10.5281/zenodo.21825389) or see the *Citation* section of the main README.
