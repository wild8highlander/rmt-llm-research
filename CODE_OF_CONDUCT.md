# Code of Conduct

## Our pledge

We welcome everyone who wants to work on random-matrix theory, LLM
spectroscopy, or the tooling around them. Participation is expected to be
free of harassment, personal attacks and discrimination of any kind.

## Expected behaviour

- Critique results, formulas and code — not people.
- Extra scrutiny for extraordinary claims: this repository makes strong
  mathematical claims (inevitable hallucination thresholds, BBP-style
  transitions in activations), so authors should expect and welcome requests
  for derivations, reproducible scripts and data.
- Keep discussions in English or Russian; both are official languages of
  this repository.

## Unacceptable behaviour

Harassment, trolling, publishing others' private information, or any
conduct a reasonable person would consider inappropriate in a professional
research setting.

## Enforcement

Report violations via GitHub issues tagged `conduct`, or privately through
the contact channels in `SECURITY.md`. Maintainers may remove comments,
lock discussions and ban accounts. Decisions can be appealed once, to the
maintainer listed in `AUTHORS.md`.

This text follows the spirit of the Contributor Covenant; it is scoped to
repository spaces (issues, PRs, discussions) and any project events.
