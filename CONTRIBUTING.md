# Contributing to RMT & LLM Research

Thank you for your interest in contributing!

## How to Contribute

1. **Fork** the repository
2. Create a **feature branch**: `git checkout -b feature/your-feature`
3. Make your changes
4. **Commit** with a descriptive message
5. Open a **Pull Request** against `main`

## Contribution Types

| Type | Example |
|------|---------|
| Errata | Fix a formula, correct a reference |
| Translation | Add a new language version |
| Enhancement | Expand a section, add new analysis |
| New Content | Add new research documents |

## File Naming

- English documents: `docs/en/Descriptive_Name.docx`
- Russian documents: `docs/ru/Descriptive_Name_RU.docx`
- Papers (PDF): `papers/Descriptive_Name.pdf`

## Code of Conduct

- Be respectful and constructive
- Focus on scientific accuracy
- Provide references for claims
