The visual identity of the project. Two families live here:

| Folder | Content |
|---|---|
| [`branding/`](branding/README.md) | animated SVG logos, avatars, banners and the rendered PNG editions |
| [`charts/`](charts/README.md) | publication-grade 600 dpi figures — RMT theory panels and repository metrics |

Both families share one design language — **Black Aurora**: a deep
near-black space `#050510`, and the full northern-lights spectrum
(emerald `#00ffa3` → cyan `#22d3ee` → violet `#a78bfa` → pink
`#f472b6`) flowing over it. The SVGs animate on GitHub via embedded
CSS/SMIL — no JavaScript, so they render everywhere `<img>` works.
