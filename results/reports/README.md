The textual counterpart of [`charts/`](../charts/README.md): for every
run of the 3D research pipeline this folder stores a full report in
parallel formats — JSON, CSV, YAML, Markdown, HTML, TeX and more —
named `<timestamp>_<experiment-id>.<ext>`.

> Files ending in `.pdf.txt`, `.xlsx.txt`, … are textual stubs produced
> when an optional export backend was unavailable in the run
> environment; the canonical machine-readable formats are `.json`,
> `.csv` and `.yaml`.

Consume the `.json` / `.csv` files programmatically; the `.md` / `.html`
editions are for reading. Everything here is regenerated by:

```bash
cd laboratory/python/lab_en
python main.py    # menu item "Research 3D"
```
