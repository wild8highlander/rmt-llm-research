Word editions of the English research papers behind the repository.
They are the theoretical backbone for everything implemented in
`src/rmt_llm/`: the Marchenko–Pastur / BBP / Tracy–Widom machinery, the
"10 paths to N_crit" argument, and the Utility Trap / Hallucination
Cliff phenomena that the empirical pipelines test directly.

| File | Content |
|---|---|
| `LLM_Analysis_Merged.docx` | the merged monograph |
| `RMT_LLM_Spectral_Analysis.docx` | spectral analysis of LLM activations |
| `RMT_LLM_Arxiv_Preprint.docx` | the arXiv-style preprint |
| `RMT_LLM_BlackGold_Preprint_v1.docx` / `v2.docx` | the BlackGold preprint, versions 1–2 |
| `Complex_Analytical_Model_Inevitable_Hallucinations.docx` | the inevitability-of-hallucinations model |

A merged PDF edition lives in [`papers/`](../../papers/README.md).
