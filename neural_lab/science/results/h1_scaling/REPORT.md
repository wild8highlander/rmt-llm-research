## Что даёт лестница (мощность и устойчивость)

1. **Позитивы**: 14 (S) → 19 (M) → 19 (L) при базовой частоте ~3.4% — первичная цель
   остаётся редкой; кластерная перестановка остаётся консервативной.
2. **Направление эффекта реплицируется**: D > B во всех трёх ячейках (3/3;
   биномиальный знак-тест p=0.25, доказательная сила ограничена).
3. **Строгий предзарегистрированный критерий** (perm p < 0.05) не достигнут ни в одной
   ячейке; в L бутстреп-CI ΔAUC впервые исключает ноль: +0.116 [+0.012, +0.215].
4. **Новая находка — нестабильность confidence-baseline**: качество B_confidence
   немонотонно по масштабу (0.415 → 0.688 → 0.478). Прирост D−B — разность двух
   блуждающих величин; часть динамики ΔAUC объясняется дрейфом B, а не спектра.
   Следствие для протокола: ΔAUC(D−B) необходимо дополнять сравнением D−E и C-alone.
5. **Внутренние состояния устойчивы**: C_internal выше случая во всех ячейках
   (0.542 / 0.661 / 0.676) и стабильно сильнее B на вторичной цели во всех ячейках.
6. **Абляция спектра**: E без спектральной группы слабее D везде
   (0.412 / 0.576 / 0.547) — спектральный блок несёт уникальный сигнал на всех масштабах.

## Статус H1 и следующие шаги

- Статус в реестре: **inconclusive** (пересмотр после L: направление устойчиво,
  величина эффекта блуждает из-за нестабильности baseline).
- XL: обучение требует GPU (эпоха ~20 мин на 2-CPU, курс 150 эпох ~49 ч); пайплайн
  проверен smoke-прогоном на 12L/384h (49 признаков). Ячейка в очереди.
- Для мощности: расширение выборки задач (цель ≥ 40 позитивов на ячейку), полоса
  near-band, повтор на независимом семействе задач (этап 05 роадмапа).
