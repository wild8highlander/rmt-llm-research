Научное ядро `neural_lab`: не каталог эффектных экспериментов, а
воспроизводимый конвейер, который формулирует проверяемые гипотезы,
извлекает признаки из реальной модели, предсказывает результаты на
новых данных и измеряет, насколько его предсказания лучше случайного
угадывания и простых baseline'ов. Ключевые правила ядра: ни одного
числа «из рук» (всё генерируется прогоном), ни одной утечки
(сплиты по семействам задач, верифицируемые проверками), ни одного
непрозрачного результата (каждый прогон несёт паспорт с provenance).

## Три разделённых слоя

| Слой | Модуль | Ответственность |
|---|---|---|
| Instrumentation | [`instrumentation/`](instrumentation/) | что реально наблюдается в модели (логиты, скрытые состояния; sha256 весов) |
| Features | [`features/`](features/) | что математически вычисляется из наблюдений (спектр/MP, энтропии, динамика, геометрия) |
| Prediction | [`predictors/`](predictors/) + [`evaluation/`](evaluation/) | какой исход прогнозируется и насколько это лучше baseline |

Разделение слоёв — главный анти-утечный механизм: инструменты
наблюдения не знают о целевой переменной, извлечение признаков не
знает о предикторах, а оценка всегда сравнивает модель не только со
случайностью, но и с честным confidence-baseline. Внутри слоёв:

- **Instrumentation** — `capture.py` (логиты и скрытые состояния по
  слоям), `model_loader.py` (фиксация ревизии весов, sha256);
- **Features** — `spectral.py` (λ_max, effective rank, MP-граница),
  `confidence.py` (энтропии, margin), `temporal.py` (динамика по слоям),
  `geometry.py` (метрики пространства представлений), `build.py`
  (сборка вектора признаков по протоколу версии);
- **Prediction** — `logreg.py` (основной предиктор), `baselines.py`
  (B: confidence, E: без спектра), `calibration.py` (Brier/калибровка).

## Сквозные контуры

[`data/`](data/) — задачи с независимой верификацией (истина
пересчитывается библиотекой `src/rmt_llm`, а не хранится как строка) и
разбиения без утечек (`splits.py`, `grouped_kfold_v1` — разбиение по
семействам задач, чтобы близкие задачи не попадали в train и test
одновременно). [`storage/`](storage/) — паспорта запусков с provenance:
sha256 весов/корпуса/датасета, seeds, версии окружения. [`experiments/`](experiments/)
— CLI-прогоны (`run_h1.py`). [`results/`](results/) — зафиксированные
результаты вместе с `REPORT.md`, который генерируется из `report.json`.
[`hypotheses/registry.yaml`](hypotheses/registry.yaml) — реестр гипотез
с критериями фальсификации и статусами. [`evaluation/`](evaluation/)
дополнительно содержит `leakage_checks.py` (проверки пересечения
семейств задач) и `confidence_intervals.py` (bootstrap + перестановочные
тесты с кластеризацией по задаче).

## Быстрый старт

```bash
# 1. обучить модель, если весов ещё нет (weights gitignored, ~17 мин CPU)
python3 research/tinygpt_formula/scripts/train_formula_model.py

# 2. полный прогон эксперимента H1 (~3 мин CPU после обучения)
RMT_LLM_BASE=research/tinygpt_formula \
  python3 neural_lab/science/experiments/run_h1.py

# смок-прогон (жадная генерация, ~1 мин)
SMOKE=1 python3 neural_lab/science/experiments/run_h1.py --out /tmp/h1_smoke

# 3. тесты ядра
python3 -m pytest neural_lab/science/tests/ -q
```

Переменные окружения: `RMT_LLM_BASE` — корень исследовательской
программы с весами; `SMOKE=1` — укороченный прогон для проверки
целостности конвейера; выход всегда в отдельную папку `--out`, чтобы
никогда не перезаписать зафиксированный результат.

Результаты прогона: `results/h1_v1/REPORT.md` (генерируется из
`report.json`, не из рук). Паспорт прогона: `results/h1_v1/passport.json`
(sha256 весов/корпуса/датасета, seeds, версии окружения).

## Главный результат прогона H1 (v1.0.1, TinyGPT v3 447K)

- **Первичная цель** (предсказание численной ошибки, 14 позитивов):
  underpowered — ΔAUC(D−B) = +0.206 [+0.084, +0.319], p = 0.097;
  направление положительное, строгий критерий не достигнут.
  Абляция: без спектральной группы комбинированная модель падает до
  уровня уверенности (0.621 → 0.412) — прирост обеспечивает спектр.
- **Вторичная цель** (format_ok — «Ловушка Полезности»): **значимо** —
  внутренние спектральные состояния AUC 0.871 [0.833, 0.905] против
  стандартной уверенности 0.794 [0.740, 0.845]; ΔAUC = +0.075
  [+0.038, +0.115], перестановочный p = 0.0025.

Отрицательный/неубедительный результат — тоже результат: он зафиксирован
в реестре гипотез и определяет следующий шаг (масштабирование на
M/L/XL ячейки для мощности).

## H1 × scaling-лестница (S / M / L)

Прогон на трёх ячейках лестницы с общим датасетом (113 задач, 565
наблюдений) и общим протоколом разбиений; протокол признаков v1.1 для
M/L (пер-слоевые признаки по фактической глубине). Ячейки: S — 447K
параметров / 33 признака; M — 1.11M / 37; L — 4.06M / 45.

| Цель | S | M | L |
|---|---|---|---|
| Первичная: ΔAUC(D−B) [95% CI], perm p | +0.206 [+0.084, +0.319], p=0.097 | +0.037 [−0.042, +0.127], p=0.531 | **+0.116 [+0.012, +0.215]**, p=0.070 |
| Вторичная (format_ok): ΔAUC(D−B), perm p | +0.075, p=0.0025 | +0.037, p=0.333 | **+0.137 [+0.080, +0.195]**, p=0.0040 |

Что даёт лестница:

1. Направление D > B реплицировано во всех трёх ячейках (3/3), но
   биномиальный знак-тест даёт лишь p=0.25 — доказательная сила
   ограничена числом ячеек.
2. В ячейке L бутстреп-CI первичной цели впервые исключает ноль;
   строгий предзарегистрированный критерий (perm p < 0.05) пока не
   достигнут ни в одной ячейке.
3. Новая находка: **confidence-baseline нестабилен по масштабу**
   (0.415 → 0.688 → 0.478), поэтому часть динамики ΔAUC(D−B)
   объясняется дрейфом B, а не спектра; протокол дополняется
   сравнениями D−E и C-alone.
4. Абляция спектра (E без спектральной группы) слабее полной модели
   на всех масштабах (0.412 / 0.576 / 0.547) — спектральный блок несёт
   уникальный сигнал везде.

Статус H1 в реестре: **inconclusive** (направление устойчиво, величина
эффекта блуждает из-за нестабильности baseline). XL-ячейка в очереди —
требует GPU (эпоха ~20 мин на 2-CPU, курс 150 эпох ~49 ч); пайплайн
проверен smoke-прогоном на 12L/384h (49 признаков). План мощности:
≥ 40 позитивов на ячейку, полоса near-band, повтор на независимом
семействе задач (этап 05 роадмапа).

## Реестр гипотез

| ID | Формулировка (кратко) | Статус |
|---|---|---|
| H1 | спектр активаций предсказывает ошибки сверх confidence | inconclusive |
| H2 | обучение на правильных формулах снижает уверенные галлюцинации при наличии знания | inconclusive |
| H3 | BBP-выброс λ_max разделяет «известные» и фабрикуемые ответы | inconclusive |
| H4 | N_crit как спектральный порог воспроизводим на независимых моделях | registered |

## Как читать результаты

- **ΔAUC** — разность ROC-AUC против baseline; доводится с 95%
  bootstrap-CI: интервал, не содержащий 0, — эмпирический эффект.
- **perm p** — перестановочный p-value с кластеризацией по задаче
  (наблюдения одной задачи не считаются независимыми); строгий
  предзарегистрированный критерий — p < 0.05.
- Позитивы первичной цели редки (~3.4% наблюдений), поэтому «мощность»
  определяется числом позитивов, а не только объёмом выборки.
