The scientific kernel of `neural_lab`: not a gallery of flashy
experiments, but a reproducible pipeline that formulates testable
hypotheses, extracts features from a real model, predicts outcomes on
held-out data, and measures how much better its predictions are than
chance and simple baselines. The kernel's ground rules: no numbers "by
hand" (everything is generated by a run), no leaks (family-based splits
verified by dedicated checks), and no opaque results (every run carries
a passport with full provenance).

## Three separated layers

| Layer | Module | Responsibility |
|---|---|---|
| Instrumentation | [`instrumentation/`](instrumentation/) | what is actually observed in the model (logits, hidden states; sha256 of the weights) |
| Features | [`features/`](features/) | what is mathematically computed from observations (spectrum/MP, entropies, dynamics, geometry) |
| Prediction | [`predictors/`](predictors/) + [`evaluation/`](evaluation/) | which outcome is predicted and by how much it beats the baseline |

The layer separation is the core's main anti-leak mechanism:
instrumentation knows nothing about the target, feature extraction knows
nothing about the predictors, and evaluation always compares the model
not only to chance but to an honest confidence baseline. Inside the
layers:

- **Instrumentation** — `capture.py` (logits and hidden states per
  layer), `model_loader.py` (weight revision pinning, sha256);
- **Features** — `spectral.py` (λ_max, effective rank, MP bound),
  `confidence.py` (entropies, margin), `temporal.py` (layer dynamics),
  `geometry.py` (representation-space metrics), `build.py`
  (protocol-versioned feature vector assembly);
- **Prediction** — `logreg.py` (main predictor), `baselines.py`
  (B: confidence, E: minus spectral), `calibration.py` (Brier/calibration).

## Cross-cutting loops

[`data/`](data/) — tasks with independent verification (ground truth is
recomputed by the `src/rmt_llm` library rather than stored as a string)
and leak-free splits (`splits.py`, `grouped_kfold_v1` — grouping by
task family so sibling tasks never land in train and test together).
[`storage/`](storage/) — run passports with provenance: sha256 of
weights/corpus/dataset, seeds, environment versions. [`experiments/`](experiments/)
— CLI runners (`run_h1.py`). [`results/`](results/) — fixed results,
each with a `REPORT.md` generated from `report.json`.
[`hypotheses/registry.yaml`](hypotheses/registry.yaml) — the hypothesis
registry with falsification criteria and statuses. [`evaluation/`](evaluation/)
additionally provides `leakage_checks.py` (task-family overlap checks)
and `confidence_intervals.py` (bootstrap + permutation tests clustered
by task).

## Quick start

```bash
# 1. train the model if weights are missing (weights gitignored, ~17 min CPU)
python3 research/tinygpt_formula/scripts/train_formula_model.py

# 2. full H1 experiment run (~3 min CPU after training)
RMT_LLM_BASE=research/tinygpt_formula \
  python3 neural_lab/science/experiments/run_h1.py

# smoke run (greedy generation, ~1 min)
SMOKE=1 python3 neural_lab/science/experiments/run_h1.py --out /tmp/h1_smoke

# 3. core test suite
python3 -m pytest neural_lab/science/tests/ -q
```

Environment variables: `RMT_LLM_BASE` — root of the research program
holding the weights; `SMOKE=1` — a reduced run for pipeline integrity
checks; output always goes to a separate `--out` folder so a fixed
result is never overwritten.

Run output: `results/h1_v1/REPORT.md` (generated from `report.json`,
not from hands). Run passport: `results/h1_v1/passport.json`
(sha256 of weights/corpus/dataset, seeds, environment versions).

## Main H1 result (v1.0.1, TinyGPT v3 447K)

- **Primary endpoint** (numeric-error prediction, 14 positives):
  underpowered — ΔAUC(D−B) = +0.206 [+0.084, +0.319], p = 0.097;
  the direction is positive, the strict criterion was not met.
  Ablation: without the spectral group the combined model falls back to
  the confidence level (0.621 → 0.412) — the gain comes from the spectrum.
- **Secondary endpoint** (format_ok — the "Utility Trap"): **significant** —
  internal spectral states AUC 0.871 [0.833, 0.905] vs standard
  confidence 0.794 [0.740, 0.845]; ΔAUC = +0.075 [+0.038, +0.115],
  permutation p = 0.0025.

A negative or inconclusive result is still a result: it is recorded in
the hypothesis registry and it defines the next step (scaling to the
M/L/XL cells for statistical power).

## H1 × scaling ladder (S / M / L)

A run over three ladder cells with a shared dataset (113 tasks, 565
observations) and a shared split protocol; feature protocol v1.1 for
M/L (per-layer features by actual depth). Cells: S — 447K parameters /
33 features; M — 1.11M / 37; L — 4.06M / 45.

| Endpoint | S | M | L |
|---|---|---|---|
| Primary: ΔAUC(D−B) [95% CI], perm p | +0.206 [+0.084, +0.319], p=0.097 | +0.037 [−0.042, +0.127], p=0.531 | **+0.116 [+0.012, +0.215]**, p=0.070 |
| Secondary (format_ok): ΔAUC(D−B), perm p | +0.075, p=0.0025 | +0.037, p=0.333 | **+0.137 [+0.080, +0.195]**, p=0.0040 |

What the ladder gives:

1. The direction D > B replicated in all three cells (3/3), but the
   binomial sign test gives only p=0.25 — the evidence is limited by the
   number of cells.
2. In the L cell the bootstrap CI of the primary endpoint excludes zero
   for the first time; the strict pre-registered criterion
   (perm p < 0.05) has not been met in any cell yet.
3. New finding: **the confidence baseline is unstable across scale**
   (0.415 → 0.688 → 0.478), so part of the ΔAUC(D−B) dynamics is
   explained by baseline drift rather than the spectrum; the protocol is
   being extended with D−E and C-alone comparisons.
4. The spectral ablation (E, no spectral group) is weaker than the full
   model at every scale (0.412 / 0.576 / 0.547) — the spectral block
   carries unique signal everywhere.

H1 registry status: **inconclusive** (the direction is stable; the
effect size wanders due to baseline instability). The XL cell is queued
— it requires a GPU (an epoch takes ~20 min on 2 CPUs; the 150-epoch
course is ~49 h); the pipeline is smoke-verified at 12L/384h (49
features). Power plan: ≥ 40 positives per cell, a near-band strip, and
a replication on an independent task family (roadmap stage 05).

## How to read the results

- **ΔAUC** — ROC-AUC difference against the baseline, reported with a
  95% bootstrap CI: an interval excluding 0 is an empirical effect.
- **perm p** — permutation p-value clustered by task (observations of
  one task are not independent evidence); the strict pre-registered
  criterion is p < 0.05.
- Positives of the primary endpoint are rare (~3.4% of observations), so
  "power" is determined by the number of positives, not just sample size.
