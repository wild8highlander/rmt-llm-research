# Stage 4 — interpretability bridge

Connects the RMT signal to mechanistic interpretability:

- `logit_lens.py` — logit-lens view of the predicted directions
- `activation_patching.py` — patching experiments on the flagged directions
- `heavy_tail.py` — heavy-tail diagnostics of the weight spectra
- `sae_bridge.py` — bridge to sparse-autoencoder features
- `run_stage4.py` — entry point
