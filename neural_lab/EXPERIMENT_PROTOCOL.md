**Эксперимент № 1: предсказание ошибки LLM по внутренним признакам**
`experiment_id: error_prediction_rmt_v1` · `hypothesis_id: H1` ·
`protocol_version: 1.0` · статус: **заморожен до прогона**

## 1. Гипотеза

**H1.** Спектральные характеристики внутренних активаций (собственные
значения ковариаций скрытых состояний относительно границ
Марченко–Пастура) содержат информацию об ошибках модели **сверх** той,
которую дают стандартные показатели уверенности (вероятности, энтропии,
perplexity).

Научно проверяемое следствие: комбинированный предсказатель D
(confidence + internal) значимо улучшает ROC-AUC относительно
предсказателя B (только confidence) на отложенных задачах, и прирост
сохраняется при leave-one-family-out.

Операциональные границы: «ошибка» = числовое расхождение с истиной в
заданном допуске, а не «галлюцинация/обман/намерение». Спектральный
сдвиг не интерпретируется как намерение модели.

## 3. Задачи и независимая разметка

Три полосы сложности (band), происхождение каждой задачи промаркировано:

| Band | Происхождение | Количество | Ожидание |
|---|---|---|---|
| `indist` | пары из обучающего корпуса (правая часть — истина от библиотеки) | 96 (пилот 48 → расширено до прогона) | модель частично «знает» ответы |
| `near` | параметры корпуса, возмущённые на ±4–7 % | 16 | зона интерполяции |
| `far` | каноническая held-out сетка свежих параметров | 37 | экстраполяция, numeric ≈ 0 |

Независимый проверяющий: истина **пересчитывается библиотекой**
(`src/rmt_llm`: `marchenko_pastur`, `bbp_transition`, `caputo_fractional`,
`tracy_widom`) из параметров промпта, а не берётся из строки корпуса.
Пары корпуса, чья правая часть расходится с пересчётом, исключаются с
записью причины (обнаружение дрейфа корпуса). Семейства без
верификатора исключаются (журнал в `tasks.json`).

Целевая переменная (первичная): `numeric_ok_025` — все числовые поля
ответа в пределах **±25 %** от истины. Сетка чувствительности
**[±15 %, ±25 %, ±40 %]** зафиксирована заранее. Обоснование допуска:
при ±15 % (стандарт research-бенчмарка) позитивы на этой модели
практически отсутствуют; ±25 % выбрано до просмотра полных данных, по
результатам пилота, в сторону УВЕЛИЧЕНИЯ мощности, а не подбора
результата (выбор усложняет задачу предсказателя не меньше, чем ±15 %).

Вторичная цель (заявлена заранее): `format_ok` — воспроизведение
структуры ответа («Ловушка Полезности»: уверенная форма при
ненадёжном содержании).

Генерация: **4 сэмплированных ответа** (T = 0.8, seed =
crc32(task_id)·100 + i) + **1 жадный** на задачу; `max_new_tokens = 28`.

## 4. Признаки (замороженный список — 33)

| Группа | n | Состав |
|---|---|---|
| `confidence` | 7 | ce_first, ce_mean, ppl_answer, maxprob_first, maxprob_mean, entropy_mean, margin_first |
| `spectral` | 15 | gap_ratio_L0..L3, effrank_L0..L3, gap_ratio_mean, gap_ratio_last, effrank_mean, effrank_last, participation_mean, ncrit_free_last, lambda_max_last |
| `temporal` | 7 | lam_traj_slope/mean/std, ent_traj_slope/delta, ce_traj_slope/std |
| `geometry` | 4 | rep_norm_mean, rep_norm_last, drift_mean, drift_last |

Конвенции спектра: ковариация представлений по позициям (T, H);
при T < H (rank-дефицит) sigma² = trace/H (полная дисперсия), q = H/T,
MP-граница = sigma²·(1+√q)²; `gap_ratio` = λ_max/MP-граница. Конвенция
проверена контрольными нулями: у белого шума gap_ratio ∈ [0.85, 1.15]
(`tests/test_spectral.py`). Порядок признаков зафиксирован в
`features/build.py`; наблюдения с нечисловыми признаками исключаются с
записью причины.

Группы моделей:

| Модель | Признаки |
|---|---|
| A | ConstantRateBaseline (базовая частота train) |
| A2 | FamilyRateBaseline (частота по семейству, сглаживание Лапласа) |
| B | confidence |
| C | internal = spectral + temporal + geometry |
| D | combined = confidence + internal |
| E | combined минус spectral (абляция «что теряется без спектра») |

Предсказатель: L2-логистическая регрессия (l2 = 1.0, Ньютон, стандартизация
по train-фолду) на чистом NumPy.

## 5. Разбиения и проверки утечек

Первичная схема `grouped_kfold_v1`: 5 фолдов по ЗАДАЧАМ (все повторные
генерации задачи остаются в одной части), стратификация по
(family × band), seed 42. Формальные проверки перед каждым фитом:
пересечение задач train/test запрещено (`LeakageError`), дубликаты
промптов между частями запрещены. Пересечение СЕМЕЙСТВ в первичной
схеме допустимо по дизайну; строгий контроль обобщения — отдельная
схема `leave_one_family_out` (обучите на 4 семействах → тест на 5-м).

Калибровка Платта — только на данных обучения: внутри каждого train-фолда
задачи делятся 80/20 на фит- и калибровочную части; тест никогда не
участвует ни в фите, ни в калибровке.

## 6. Метрики и критерии успеха

Совместно оцениваются (все — на pooled out-of-fold предсказаниях):

| Метрика | Что показывает |
|---|---|
| ROC-AUC (+ кластерный 95 % CI) | ранжирование ошибок |
| PR-AUC (average precision) | выявление ошибок при дисбалансе |
| Brier, log loss | точность вероятностей |
| ECE (10 равно-массовых бинов), до и после Платта | калибровка |
| ΔAUC(D−B), ΔAUC(D−C), ΔAUC(C−B) | прирост групп признаков |

Неопределённость: **кластерный бутстреп по задачам** (2000 реплик) —
повторные генерации одной задачи коррелированы; перцентильный CI.
Проверки:

1. **Кластерный парный перестановочный тест** ΔAUC (2000 перестановок):
   целая задача обменивается между предсказаниями двух моделей.
2. **Перестановка меток** (до 500 реплик): метки перемешиваются на
   уровне задач внутри страт (family × band); проверка на «сверхъестественно
   хороший» AUC против нуля «признаки не связаны с меткой».
3. **LOFO**: точечные AUC на незнакомом семействе.

**Критерий успеха H1**: ΔAUC(D−B) > 0, 95 % CI не накрывает 0, И
кластерный перестановочный p < 0.05. Критерий провала: CI накрывает 0
или эффект исчезает при LOFO. **Отрицательный результат публикуется
как есть** — это полезный исход, ограничивающий область применимости
спектральных признаков.

## 7. Мощность и честные ограничения

- 447K-модель: численная точность ≈ 0 на far; позитивы сосредоточены в
  indist. Пилот: numeric_ok ≈ 0 при жадной генерации → расширение
  indist до 96 пар + сэмплирование T=0.8.
- Если позитивов < ~20, первичная цель считается **underpowered**:
  отчёт фиксирует это явно, основной статистический вес смещается на
  вторичную цель format_ok (заявлена заранее).
- Один seeded-прогон обучения; веса не коммитятся (воспроизводство —
  скриптом); повторные запуски полного пайплайна детерминированы при
  тех же весах.
- Результаты относятся к TinyGPT v3 (447K) и данному классу задач;
  перенос на другие модели — отдельная проверка (Roadmap, этап 05).
