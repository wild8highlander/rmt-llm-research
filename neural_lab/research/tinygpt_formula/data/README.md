# 🗂️ data — Corpora

<p align="center">
  <em>The formula corpus and its control twin</em><br><br>
  <a href="../README.md"><img src="https://img.shields.io/badge/folder-research-a78bfa" alt="tinygpt_formula/"></a>
  <img src="https://img.shields.io/badge/corpus-00ffa3" alt="corpus"><img src="https://img.shields.io/badge/train%20%2B%20val%20%2B%20control-22d3ee" alt="train+val+control">

The training and evaluation corpora for the Formula-Edition experiment —
and, crucially, its **control twin**. The experiment is an A/B design:
the `formula` corpus carries true project formulas, the `control` corpus
is a structurally identical but content-free counterpart. Any
difference in confident-hallucination behaviour between the two models
is therefore attributable to the content, not to surface statistics.
This is the same design logic as a placebo arm in medicine: without the
twin, "the formula model is better" could always be explained by extra
training or by vocabulary; with the twin, only the *truth of the
numbers* is left as the difference.

## Files

| File | Role |
|---|---|
| `formula_corpus_train.txt` / `formula_corpus_val.txt` | formula corpus — train / held-out validation |
| `formula_corpus_train_control.txt` / `formula_corpus_val_control.txt` | the control corpus — same shape, no true formulas |
| `corpus_stats.json` | sizes, token counts and overlap statistics for both corpora |

## What the corpus teaches

| Source | Knowledge type | Example content |
|---|---|---|
| `src/rmt_llm/` docstrings & code | structure of a correct answer | Marchenko–Pastur bounds, BBP, Tracy–Widom, NHSE, Caputo, Keating–Snaith |
| computational pairs | parameters → exact numbers | self-verified pairs generated by the library itself |
| monograph excerpts | project vocabulary & concepts | IEEE 754 microcollapses, Utility Trap, Landauer, N_crit = gamma_1 / theta_b |

## How the control twin is built

`build_control_corpus.py` (seed 42) keeps every token of text identical
and replaces only the numerical results inside the computational pairs
with deterministic corruptions. Consequently the twin matches the
formula corpus in size, grammar, token frequencies, and formatting —
everything a model could learn from *form* is identical; everything that
differs is *truth of content*. The corruption map itself is committed in
the build script, so the twin is exactly reproducible and the A/B
comparison is never a one-off.

## Determinism and provenance

- Rebuilding from the same repository state produces byte-identical
  files; the corpora are hashed and downstream reports record the hash.
- If a rebuilt corpus diverges, that divergence is information (the core
  changed) — and the canonical files here take priority for reproducing
  historical artifacts.
- Validation split is held out by task family, mirroring the
  leakage-free split policy of the science core in
  [`../../../science/README.md`](../../../science/README.md).

Build or rebuild the corpora with
[`scripts/build_corpus.py`](../scripts/README.md); the study that
consumes them is [`scaling/`](../scaling/README.md).
