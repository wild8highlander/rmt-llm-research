TL;DR Why LLMs hallucinate, mathematically.

Large language models exhibit fundamentally different spectral statistics depending on whether they are in factual recall or creative generation mode. By computing the covariance matrix M = XnT Xn / T of hidden-state activations and analysing its eigenvalue distribution, we can:

  • Detect cognitive mode — factual generation produces a Marchenko-Pastur bulk + a separated outlier (BBP transition); creative generation produces a Tracy-Widom-distributed largest eigenvalue with no clear signal-bulk separation.
  • Predict hallucination onset — ten independent mathematical arguments converge on the same critical token count N_crit, beyond which autoregressive generation inevitably collapses.
  • Quantify RLHF damage — RLHF optimization creates an artificial drift in the Fokker-Planck equation; with Caputo memory parameter β ≈ 0.5, the mean collapse time scales as ⟨T_crit⟩ ∝ (μ_eff)-2 — even small RLHF pressure quadratically accelerates hallucination.
The core claim. Hallucinations in autoregressive LLMs are not a bug — they are a mathematical inevitability of finite-context, finite-precision autoregression. The same spectral mechanism that lets the model generate fluent text also guarantees that beyond N_crit tokens, the probability of factually correct output decays faster than exponentially.

Three research threads

thread 1

Spectral statistics of LLM activations

Covariance matrices of GPT-2 hidden-state activations exhibit fundamentally different spectral properties depending on whether the model is in factual recall or creative generation mode. The BBP phase transition, Marchenko-Pastur bounds, and Tracy-Widom fluctuations provide quantitative markers for cognitive mode detection.

thread 2

Inevitable hallucinations

Ten independent mathematical paths converge on a single critical token count N_crit: complex phase, operator dynamics, GUE spectral statistics, thermodynamic entropy, Lévy-Langevin fractional dynamics, EP-surfaces, Tracy-Widom, quantum channel degradation, NHSE winding number, and Caputo fractional-time memory.

thread 3

The utility trap: RLHF and entropic collapse

RLHF optimization creates an artificial drift in the Fokker-Planck equation, forcing the model to "lie beautifully once" rather than risk a self-correction cycle. The Caputo memory parameter β ≈ 0.5 makes ⟨T_crit⟩ ∝ (μ_eff)-2.

Interactive demo

Explore the four key mathematical objects underlying the theory. All computations run in your browser — no server, no API calls.

1. Marchenko-Pastur law

ρ(λ) = (1/(2π σ² λ q)) · √((λ_+ − λ)(λ − λ_-)), λ_± = σ²(1 ± √q)²
λ_- = 0.086, λ_+ = 2.914

2. BBP phase transition

λ_max → { λ_+ (θ ≤ √q) | σ²(1 + θ²/q) (θ > √q) }
θ = 0.80, √q = 0.707 → TRANSITION (λ_max = 1.28 above bulk edge)

3. Tracy-Widom F₂(s)

F₂(s) = exp(-∫_s^∞ (x − t)² μ₂(t) dt) — GUE largest-eigenvalue CDF
F₂(0.00) = 0.8319 — 83.2% of random matrices have λ_max below this threshold

4. NHSE winding number

w = (1/2π) ∮ arg(det(H(z) − λ)) dz — transition w: 0 → 1 at N = N_crit
w = 0 (below transition) — eigenvalues on a 2D ring, Im(λ) ≠ 0

How to use: drag the sliders to explore each mathematical object. The Marchenko-Pastur visualiser shows the bulk eigenvalue density of a random covariance matrix — adjust q to see the bulk shrink or grow. The BBP transition shows how a "signal" eigenvalue pops out of the bulk when θ > √q. The Tracy-Widom distribution governs the fluctuations of the largest eigenvalue around the BBP threshold. The NHSE simulator shows the topological transition that drives hallucination onset.
