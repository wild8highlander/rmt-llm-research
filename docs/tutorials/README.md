Rendered, static versions of the first four Jupyter notebooks — same
material, readable without a notebook server. Each tutorial is
executable top-to-bottom on a CPU-only machine and ends with
something concrete: a trained model, a generated text, or a spectral
diagnosis.

| Tutorial | You will… |
|---|---|
| [`01-quickstart.md`](01-quickstart.md) | install, verify the environment, run the first RMT analysis |
| [`02-training-tinygpt.md`](02-training-tinygpt.md) | train TinyGPT from scratch with the BPE tokenizer |
| [`03-generation-and-sampling.md`](03-generation-and-sampling.md) | play with temperature / top-k / top-p sampling |
| [`04-multilingual-labs.md`](04-multilingual-labs.md) | run the same lab from the 8 language implementations |
| [`index.md`](index.md) | the tutorial index used by the docs site |

Prefer an interactive run? The live counterparts are in
