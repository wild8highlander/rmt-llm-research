The `r/` folder hosts the R port of the research laboratory, split into
the same two language variants used across the whole laboratory tree.
R is the natural home for the statistical half of the project: the
Marchenko–Pastur fits, spectral entropy estimates and Tracy–Widom
comparisons are expressed with base-R and lightweight plotting, without
pulling heavy dependencies.

| Folder | Content |
|---|---|
| [`lab_en/`](lab_en/) | English variant — `main.R` menu + `research_3d.R` pipeline |
| [`lab_ru/`](lab_ru/) | Russian variant — same code, translated UI strings |

## 🚀 Quick start

```bash
cd laboratory/r/lab_en
Rscript main.R
```
