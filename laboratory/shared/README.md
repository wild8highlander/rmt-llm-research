# 🧩 shared — Common Ground

<p align="center">
  <em>Assets shared by every language twin of the laboratory</em><br><br>
  <img src="../../assets/branding/aurora-divider.svg" width="420" alt=""><br><br>
  <a href="../README.md"><img src="https://img.shields.io/badge/folder-shared-1C2340" alt="laboratory/"></a>
  <img src="https://img.shields.io/badge/cross----language-22d3ee" alt="cross-language">
</p>

The place where the eight language twins of the laboratory meet:
material that must stay byte-identical across implementations —
reference values, scenario definitions and shared fixtures — lives here
instead of being duplicated per language. When a scenario changes, it
changes once, here, and every twin picks it up on the next run.

See the family: [python](../python/README.md) ·
