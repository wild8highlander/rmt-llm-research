# Глава 1 — Область действия, допущения и обозначения

*Формальное дополнение к программе rmt-llm-research. Эта монография
содержит только те утверждения, которые выведены из явно
сформулированных допущений и проверены численно; всё остальное в
родительском репозитории остаётся феноменологическим и намеренно не
трогается.*

## 1.1 Что здесь означает «из первых принципов»

Исследовательская программа репозитория связывает спектральный анализ
активационных матриц LLM с математической неизбежностью галлюцинаций
через теорию случайных матриц (RMT). В феноменологической форме ключевые
формулы постулируются: балк Марченко–Пастура (MP), выпадающие значения
(BBP), энтропийные оценки. Настоящая монография повышает до статуса
*выведенных теорем* строго определённое подмножество этих утверждений:
каждый результат ниже — это либо (i) теорема из литературы по RMT с
точными условиями её применимости, либо (ii) алгебраический вывод из
ранее установленных результатов этой программы, либо (iii) определение.
Больше ничего не утверждается.

Разделяющая линия проведена намеренно жёстко. Там, где микроскопический
вывод требует свойств обученных трансформерных активаций, которые
сейчас *не являются теоремами* (универсальность для зависимых нелинейных
рекурсий, свободность обученных весовых матриц, концентрационные оценки
траекторий декодирования), мы не приводим доказательство и не
импортируем утверждение. Эти части 15-шаговой программы остаются ровно
там, где они есть — феноменологическими, в родительском репозитории.

## 1.2 Реестр допущений

Каждая теорема ссылается на используемые ею допущения.

| # | Допущение | Статус |
|---|-----------|--------|
| **A1** | *Белая модель элементов.* $X = \Sigma^{1/2} Z$, где $Z\in\mathbb{R}^{N\times T}$ (или $\mathbb{C}^{N\times T}$) имеет i.i.d. элементы с нулевым средним и дисперсией $\sigma^2$; $\Sigma$ — детерминированная популяционная ковариация. | Стандартно; точно для линейных моделей со случайными весами, гипотеза моделирования для обученных сетей |
| **A2** | *Пропорциональная асимптотика.* $N, T\to\infty$, $q = N/T \to q^* \in (0,\infty)$. | Точный режим всех цитируемых теорем RMT |
| **A3** | *Гауссовость промежуточного слоя.* Пре-активации на входе нелинейности совместно гауссовы с ковариацией, отслеживаемой моментной прогонкой. | Точно для линейных моделей; количественно проверенное приближение для нелинейных слоёв (гл. 2, эксперимент 6) |
| **A4** | *Асимптотическая свободность.* Семейства, чьи произведения рассматриваются, асимптотически свободны. | Теорема (Войкулеску) для i.i.d./унитарно-инвариантных семейств; для обученных весов не установлена |
| **A5** | *Около-равномерный базис декодирования.* Вектор логитов $z_0$ до шума мал (высокая температура / равномерное предсказание). | Явно сформулировано в гл. 8; там же проверено |

## 1.3 Обозначения

| Символ | Смысл |
|--------|-------|
| $N,\ T$ | размерность активаций; число токенов (длина контекста) |
| $q = N/T$ | отношение размерностей |
| $\sigma^2$ | эффективная дисперсия шума балка (параметр, который феноменологический слой привязывает к нормам весов) |
| $X,\ C = \tfrac1T XX^{\mathsf T}$ | матрица активаций и её (выборочная) ковариация |
| $\lambda_\pm = \sigma^2(1\pm\sqrt q)^2$ | края MP-балка (теорема 3.2) |
| $\mu,\ \mu_c = \sigma^2\sqrt q$ | аддитивная сила спайка и BBP-порог (теорема 5.1) |
| $m(z)=\int\frac{d\mu(\lambda)}{\lambda-z}$, $G(z)=-m(z)=\frac1N\mathrm{Tr}(zI-C)^{-1}$ | преобразования Стилтьеса (две конвенции) |
| $F_\beta$ | закон Трейси–Уидома индекса $\beta$ (гл. 9) |
| $H(p)=-\sum_i p_i\log p_i$ | энтропия Шеннона предиктивного распределения |
