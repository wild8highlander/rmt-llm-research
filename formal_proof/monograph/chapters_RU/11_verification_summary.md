# Глава 11 — Сводка верификации

Все результаты монографии проверены набором экспериментов в
`formal_proof/experiments/`. Одна команда воспроизводит всё
(~3 минуты, только CPU):

```bash
cd formal_proof/experiments
python3 run_all.py
```

## 11.2 Воспроизводимость

* Зерна зафиксированы в каждом скрипте; результаты детерминированы с
  точностью до шума MC.
* Зависимости: `numpy`, `scipy`, `matplotlib`, `pillow` (см.
  `formal_proof/requirements.txt`). Без GPU и сети.
* Рисунки складываются в `formal_proof/assets/figures/`, анимации в
  `assets/animations/` — оба коммитятся, поэтому монография рендерится
  без перезапуска чего-либо.

## 11.3 Известные конечномерные эффекты (документированы честно)

* Наибольшее собственное значение сидит чуть *ниже* $\lambda_+$ на
  докритических спайках — это масштаб Трейси–Уидома главы 9, а не ошибка.
* Центрирование Джонстона оставляет смещение $\mathcal O(N^{-1/2})$ в
  стандартизованном среднем TW при $N\sim200$; поправка Эль-Каруи
  (`el_karoui_center_scale`) его уменьшает.
* Генераторы TW из GOE/GUE медленно сходятся по $p$; набор сравнивает
  *распределения* (двухвыборочный КС), что устойчиво к остаточному
  смещению, и приводит абсолютные моменты только как диагностику.
* Энтропийные члены третьего порядка видны при $\tau \lesssim 2$;
  теорема 8.2 — утверждение второго порядка и не должна экстраполироваться
  на низкие температуры.
