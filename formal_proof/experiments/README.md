# formal_proof/experiments — executable proofs

Numerical experiments that verify the claims of `formal_proof/rmt_fp/`:

| script | verifies |
| --- | --- |
| `verify_mp_law.py` | Marchenko-Pastur law for layer operators |
| `verify_bbp_transition.py` | BBP transition of spiked eigenvalues |
| `verify_entropy.py` | entropy bounds used in the hallucination split |
| `verify_layer_ops.py` | algebra of the layer-operator model |
| `make_mp_animation.py` | animation for the monograph |
| `run_all.py` | runs the whole suite and renders the report |

Style helpers in `_style.py`. Chapters of the written proof:
[`../monograph/`](../monograph/README.md).
